# Suspension Geometry layout / axis update

- Removed four unused, oversized geometry TextBoxes (FL/FR/RL/RR); these were made visible on startup and forced the form to scroll.
- Removed the two empty ChartAreas (`Left`, `Right`) added after `FrontSuspension` and `RearSuspension`.
- Replaced fixed chart positioning with `DockStyle.Fill` and `AutoScroll = false`.
- Added a designer-owned dark `TableLayoutPanel` toolbar with five groups: X minimum, X maximum, Y minimum, Y maximum, Update (ms).
- X/Y limits are shared by Front and Rear charts. Defaults: X −1.5 to 1.5; Y −0.5 to 1.5.
- Timer update interval defaults to 100 ms and is editable from 10–10,000 ms; the numeric input directly changes `timer1.Interval`.
- Settings are saved/restored by existing `JsonFormSettings` in `%APPDATA%\PhysicsDataDebug\Settings`.
- Plot series remain generated by the existing `SetChart()` method on `Shown`; all geometry calculations remain unchanged.
- Chart axis and legend text is now opaque and more visible against the dark background.

Designer workflow: Open `FormSuspensionGeometry.cs` with **View Designer**, then **Document Outline**. Select `settingsToolbar`, `xMinimumGroup` etc. to rearrange the toolbar or edit input defaults. No custom compiled controls are used.

No Windows Forms runtime was available in this environment; check the display at the desired Windows DPI setting.
